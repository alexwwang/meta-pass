# docs/assets/

本目录保存 fork 项目的补充文档与素材（上游 `main` 中本目录只保留 `.gitkeep`）。

## 用途

根目录 `README.md` 放不下或不属于产品落地页的内容：架构设计、决策记录、协议约定等。

## 目录结构

- `meta-pass-design.md` / `meta-pass-design.zh_CN.md` — meta-pass 固件启动器的设计文档（单一权威来源）。

## AI 使用方法

进入仓库时先读上游 `docs/README.md` 了解基线，再读本目录获取 fork 项目（meta-pass）的设计上下文。
动手修改 meta-pass 相关代码前必须先读 `meta-pass-design.md`。

## 边界

本目录内容仅存在于 fork / 功能分支，不得同步回上游 `main`。
