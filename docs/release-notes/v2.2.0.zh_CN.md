# 发布说明 — meta-pass v2.2.0

**一句话：** 新增 v2 整机存储快照备份与还原，覆盖动态分配的子固件 DATA 分区。恢复前会校验归档及目标分区布局，再执行擦除；不会把归档中的 NVS 写回目标设备。在已测设备上，恢复后重启能够正常进入 MetaPass 并重新连接。

## 新增能力

### 整机快照备份与还原

- 新增 v2 快照归档流程，备份和恢复符合条件的已分配存储区域，包括未出现在当前运行时物化分区表中的子固件 DATA 分区。
- USB 服务页同时支持历史 v1.1 归档和 v2 快照。手机内嵌页只支持 v2；遇到 v1.1 归档时，会在查询设备状态或发起 Flash 写入请求前明确拒绝。
- USB 与手机内嵌页共享 v2 归档契约和恢复安全规则；本地固件文件安装仍是 USB 页面独有功能。
- 会校验归档中 NVS 元数据的完整性，但绝不将归档 NVS 写入目标设备。目标设备原有的 NVS（包括 Wi-Fi 凭据和设备本地状态）保持不变。
- 首次擦除前校验归档完整性，并确认快照覆盖目标设备所有符合条件的已分配分区。目标分区表形状不匹配时，会在任何擦除发生前拒绝恢复。

### 子固件 DATA 快照覆盖

- 快照 inventory 以及设备侧读/擦除/写入操作，现可按持久化身份解析 carve DATA 分区，包括当前未物化进分区表的 DATA 区域。
- 修复了此前可能静默漏掉非活动子固件 DATA、导致其未进入快照的问题。

## 验证结果

在一台 8 MiB Flash 的 ESP32-C3 AI Passport 专用测试设备上：

- USB v2 快照备份通过。
- USB v2 快照恢复通过；人工重启后 MetaPass 正常启动并重新连接。
- 手机内嵌页 v2 快照恢复通过；人工重启后 MetaPass 正常启动并重新连接。
- 独立读取的 Flash 数据与归档中 **44/44 个 extent 逐字节一致**，包括子固件 DATA 区域。
- 目标分区表形状不匹配的归档在首次擦除前被拒绝。
- USB v1.1 兼容性通过主机测试；由于测试设备采用动态分区模式，本轮未在真机上执行 v1.1 恢复。

本轮没有在真机上重新验证手机内嵌页的备份流程。手机页恢复测试通过本地路由加载当前分支模块；测试时实际部署的 CDN 模块落后于分支。因此，在认定正式发布验证全部完成前，还需要确认部署页面与分支一致，并补做手机页备份真机验证。

## 升级与兼容性说明

- **USB 服务页：** 支持 v1.1 历史归档和 v2 快照。
- **手机内嵌页：** 仅支持 v2 快照。需要恢复 v1.1 归档时，请使用 USB 服务页。
- **NVS：** 归档内 NVS 会被保留并校验，但不会覆盖目标设备的 NVS。
- **恢复后的重启：** 写入成功不等于恢复验收完成；还需重启设备，并确认 MetaPass 正常启动、重新连接。
- **不提供自动回滚：** 本版本不增加事务式恢复或自动回滚。恢复前应确认归档与目标布局匹配；恢复失败时可能需要使用已知可用的归档重新恢复。
- **设备身份与分区布局：** cardid 位置及现有受保护分区布局保持不变。

## 本版本不宣称的能力

- 恢复过程中的物理断电注入测试。
- 在旧固定槽真机上执行 v1.1 归档恢复。
- 对全部 Flash 区域进行逐字节读回；本轮比对范围是归档覆盖的 44 个 extent。
- USB 与手机内嵌页已经完成源码层面的完全统一。
- 手机内嵌页备份流程的真机端到端验证，以及与当前 CDN 部署模块的一致性验证。
