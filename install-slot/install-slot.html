5. Backup (fixed-slot APP/NVS or dynamic storage snapshot)

Fixed-slot devices retain historical v1 APP/NVS backup. Dynamic devices use v2 raw storage snapshots.

6. Restore from backup (zip → slot)

USB accepts historical v1 APP/NVS archives on fixed-slot devices and v2 whole-device snapshots. An interrupted write or failed boot requires reflashing the MetaPass version recorded in the snapshot.

Select a historical v1 archive or a v2 whole-device snapshot. Interrupted restores are not rolled back; reflash the snapshot source MetaPass version before retrying.

USB fixed-slot devices retain historical v1 APP/NVS archive compatibility; dynamic layouts use v2 raw storage snapshots. ZIP files are unencrypted and may contain Wi-Fi credentials, device state and child-firmware data. Removing an APP also deletes its owned DATA.

7. Upgrade launcher (keep NVS data & child firmware)

Upgrades the launcher while keeping NVS-stored data (Wi-Fi config, per-app state) and all installed child firmware.
