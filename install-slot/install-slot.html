Write a child firmware into slot 0 / 1 / 2 over USB serial (Chrome + Web Serial).

Hold UP while powering on to enter download mode, then plug in the USB cable.

5. Backup child firmware (read slots → zip)

Reads each slot's app image, extra storage data and the 4 KB metadata sector (signature/easter egg/display name) and saves a verified zip locally.

6. Restore from backup (zip → slot)

Pick a backup zip, choose which slot each backup goes to; the page checks space and SHA-256 (from the zip's manifest), then writes firmware, extra data, and the metadata sector in order.
