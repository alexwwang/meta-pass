5. Backup child firmware (read slots → zip)

In dynamic mode, back up one complete APP+DATA group per archive; legacy layouts remain APP-only.

6. Restore from backup (zip → slot)

v2 restores one complete APP+DATA group and preserves the destination device NVS; any archived NVS bytes are verified but not written. Legacy v1 restore is not supported; restore accepts complete v2 single APP+DATA archives only.

Step 1: pick the backup zip. Step 2: target-slot pickers appear below (one per backed-up slot, defaulting to their original slots). Step 3: Restore.

USB dynamic-mode backup includes verified DATA bytes for one APP+DATA group per archive. v2 restore verifies archived NVS bytes but preserves the destination device NVS. Legacy v1 restore is not supported; restore accepts complete v2 single APP+DATA archives only. Removing an APP also deletes its owned DATA.

7. Upgrade launcher (keep NVS data & child firmware)

Upgrades the launcher while keeping NVS-stored data (Wi-Fi config, per-app state) and all installed child firmware.
